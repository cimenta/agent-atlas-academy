# Security policy

If you find a security problem in Agent Atlas, please report it privately and do not open a public issue.

- Use GitHub's private vulnerability reporting for this repository (Security tab, "Report a vulnerability").
- Or write to: agent-atlas-academy@radeksimcik.cz

Please include what you found, how to reproduce it, and what you think the impact is. We will answer as soon as we can.

Agent Atlas never stores or logs visitors' API keys. If you believe a key could leak, please report it.
